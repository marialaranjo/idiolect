# FACT_CHECK_ETHICS.md

> Última camada de revisão antes de entregar qualquer texto que envolva
> dados sensíveis, terceiros identificáveis, ou afirmações verificáveis em
> nome de [NOME]. Não é uma regra de estilo — é uma regra de **risco
> profissional**: um erro aqui pode ter implicações reais, não apenas
> estéticas. Correr sempre no fim do pipeline (ver `core/WRITING_RULES.md`).

---

## 1. Confidencialidade e proteção de dados de terceiros

- [ ] Nenhuma pessoa terceira é identificável (nome, dados que permitam
      identificação indireta) sem consentimento/necessidade
- [ ] Exemplos usados como ilustração estão suficientemente anonimizados
      ou compostos
- [ ] Se o texto envolve partilha de dados entre organizações, confirmar
      que a base legal (ex. RGPD, se aplicável) está identificada

## 2. Terminologia técnica correta

- [ ] Termos técnicos nomeados corretamente e de forma atualizada (ver
      `contexts/` ou o domínio próprio da profissão, se existir — ver
      `domains/README_DOMINIO_ESPECIFICO.md`)
- [ ] Nenhuma linguagem estigmatizante ou desatualizada
- [ ] Siglas corretas e consistentes com o período descrito

## 3. Afirmações sem dados — a verificação mais importante

- [ ] Toda a afirmação de resultado, eficácia ou impacto tem um dado, uma
      fonte ou uma citação concreta a sustentá-la
- [ ] Nenhum número, percentagem ou estatística foi inventado ou
      extrapolado além do que os dados originais permitem
- [ ] Se um dado não está confirmado, está marcado como ⚠️ lacuna a
      confirmar — nunca preenchido com suposição plausível
- [ ] Referências a terceiros/autores estão corretamente atribuídas, não
      parafraseadas de forma a distorcer o argumento original

## 4. Citações e referências, se aplicável

- [ ] Formato de citação consistente ao longo do documento
- [ ] Todas as referências citadas no corpo do texto aparecem na lista
      final, e vice-versa
- [ ] Nenhuma referência inventada ou "alucinada" — se não foi possível
      verificar uma referência via pesquisa real, não incluir

## 5. Enquadramento ético/deontológico, se aplicável

- [ ] O texto respeita o código deontológico/ético da profissão, se
      existir um formalmente
- [ ] Não há promessas de resultado além do eticamente responsável afirmar
- [ ] Se o texto é uma candidatura ou biografia, as credenciais
      apresentadas são exatas e verificáveis (ver
      `core/PROFESSIONAL_IDENTITY_TEMPLATE.md`)

## 6. Consistência interna do documento

- [ ] Datas, nomes e números são consistentes ao longo de todo o
      documento, não só na secção onde foram introduzidos
- [ ] Se o documento é longo, reler as secções finais à luz de correções
      feitas nas secções iniciais

---

## Como reportar o resultado

Não corrigir silenciosamente questões de facto ou de ética — **reportar
explicitamente**, mesmo que isso signifique atrasar a entrega:

> "Antes de entregar, sinalizo o seguinte: [lista de pontos]. Recomendo
> confirmar [X] antes de enviar, porque [risco concreto]."

Correções de estilo (não de facto) podem ser aplicadas diretamente.
Qualquer dúvida sobre **factos, ética ou confidencialidade** deve ser
levantada explicitamente para confirmação — nunca assumida silenciosamente,
mesmo que isso pareça atrasar o fluxo de trabalho. Esta é a única secção do
sistema em que "avançar rápido" nunca deve sobrepor-se a "confirmar antes
de avançar".
