# before-after/

Esta pasta está vazia de propósito. Serve para guardar exemplos de
reescrita — um texto genérico/de IA ao lado da versão corrigida para soar
a [NOME] — para calibrar `core/HUMANIZER.md` e `core/VOICE_DNA_TEMPLATE.md`
ao longo do tempo.

## Como adicionar um exemplo

1. Nomear o ficheiro: `example-01.md`, `example-02.md`, etc.
2. Estrutura sugerida:

```md
# Contexto: [tipo de documento, situação]

## Antes (genérico/IA)
[texto]

## Depois (corrigido por/aprovado por [NOME])
[texto]

## O que mudou e porquê
- [correção 1 e a regra que ilustra]
- [correção 2 e a regra que ilustra]
```

Cada exemplo aqui é uma oportunidade de promover uma hipótese 🔵 em
`core/VOICE_DNA_TEMPLATE.md` para uma regra confirmada 🟢.
