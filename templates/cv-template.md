# cv-template.md

> Um CV é mais estrutura e seleção do que "voz" — o registo importa menos
> aqui do que a clareza e a consistência com o resto dos documentos. Usar
> junto com `core/PROFESSIONAL_IDENTITY_TEMPLATE.md` para os factos.

---

## Estrutura-base (ajustar ao formato visual já usado pela pessoa, se
existir um)

```
[Nome completo]
[Credencial(is), se aplicável] | [Contacto]

## Resumo profissional
[2-3 linhas, reorientadas para a vaga específica — nunca genérico]

## Experiência
[Cargo] — [Instituição/Empresa] ([datas])
- [Responsabilidade/resultado concreto, com dado sempre que possível]
- [Responsabilidade/resultado concreto]

## Formação
[Curso] — [Instituição] ([anos])

## Competências
[Reordenar consoante o que a vaga pede primeiro — não listar tudo por
ordem cronológica de aquisição]

## Formação complementar / certificações
[Se relevante para a vaga]
```

## Regras ao adaptar um CV a uma vaga específica

1. Ler os requisitos-chave do anúncio primeiro
2. Reordenar competências e experiência para dar destaque ao que a vaga
   pede primeiro — sem inventar nem reordenar cronologia de forma
   enganosa
3. Reescrever o resumo profissional para a vaga, não copiar o mesmo texto
   para candidaturas diferentes
4. Manter o mesmo formato visual entre versões (não recriar do zero a cada
   candidatura)
5. Cortar, não encolher a fonte — se não couber no espaço, remover o menos
   relevante para esta vaga específica, não espremer tudo visualmente

## Checklist final

- [ ] Todas as datas e nomes de instituições estão corretos e consistentes
      com `core/PROFESSIONAL_IDENTITY_TEMPLATE.md`
- [ ] Nenhuma competência ou responsabilidade foi inflacionada
- [ ] O resumo profissional está reorientado para esta vaga específica
